# 📈📉 Housing Price Prediction

In this project, price prediction models are built and implemented using the Carlifonia dataset. Median house values are predicted using Ridge and Lasso models trained on multiple features.

The analysis and modeling are conducted using Python in a Jupyter Notebook, with final models saved in the `models/` folder for future use and evaluation.
